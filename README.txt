TUCASA ARU starter website
=========================

Files:
- index.html: page structure and content
- style.css: responsive styling
- script.js: mobile navigation, active section and dynamic year

How to run:
1. Keep all files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Replace sample event content, contact email, and images with official TUCASA ARU information.
4. The photos currently load from Unsplash, so an internet connection is needed for them.

This is a static front-end starter. Registration, admin updates, database storage and contact-form delivery
will require a backend or a form service.
